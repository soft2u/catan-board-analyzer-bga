PRIVACY.md

The extension reads board data already loaded in BGA's page, with visible
board elements as a fallback. It does not change the BGA board/game state or
make moves. It adds its own floating analysis control to the page.

Completed: 20 automated tests, JavaScript/manifest checks, 11-file runtime ZIP
audit, icon dimensions, and visual checks of all store images.

Before submitting: complete the developer account and required declarations;
confirm the actual service practices and publish the reviewed privacy policy;
load the final ZIP and check a fresh permitted BGA import through both controls.
GitHub releases and Chrome Web Store submission are separate steps.
