# Security Policy

## Supported version

Security fixes are applied to the latest released version of Catan BGA
Analyzer.

## Reporting a vulnerability

Please do not publish a security or privacy vulnerability in a public GitHub
issue.

Use GitHub's **Security → Report a vulnerability** private-reporting feature
for this repository. If private vulnerability reporting is not enabled, use
the private contact method published in the
[catan.soft2u.ro privacy notice](https://catan.soft2u.ro/tournaments/privacy).

Include:

- the affected extension version and browser version;
- steps to reproduce;
- the impact you observed;
- a minimal proof of concept, without real credentials, cookies, or private
  BGA game data.

Please allow reasonable time to investigate and release a fix before public
disclosure.

## Scope

Reports about unauthorized data collection, unsafe redirects, permission
expansion, code injection, or exposure of BGA credentials are in scope.
General analyzer feature requests and BGA markup changes should use normal
GitHub issues.
