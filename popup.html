Catan BGA Analyzer

Sends board tiles, numbers, harbors, and the BGA table ID when available to catan.soft2u.ro. The service saves a public, shareable board. By choosing Send, you consent to service administrators inspecting this submitted board and table ID for import support and diagnostics. It does not send cards, chat, player names, or BGA login data.

Reads board data already loaded in the BGA page, with visible board elements as a fallback. Adds its own analysis button without changing the game state or making moves.

Use only where permitted. Live strategic assistance may conflict with Board Game Arena rules or your table's fair-play expectations.
